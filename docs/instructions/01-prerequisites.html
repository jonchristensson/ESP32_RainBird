ESP32 Rain Sensor — Prerequisites & Parts List

What to buy and what to install on your PC before starting 02-flash-guide.html.

1

Install host tools

Everything below runs on your PC, not the ESP32. Install these once.

Python 3

Download from python.org/downloads if you don't already have it. Any recent Python 3.x works. During install on Windows, check "Add python.exe to PATH."

esptool and mpremote

These flash MicroPython onto the board and transfer files to it. Install both with pip:

pip install -r requirements.txt

Or individually:

pip install esptool mpremote
Full flashing steps (COM port discovery, erasing, writing the firmware) are in 02-flash-guide.html — this page only covers getting the tools installed.

3

ESP32-WROOM-32U vs 32D — which to buy

The two variants differ only in antenna: the 32D has a small trace antenna printed on the module's PCB, while the 32U has a U.FL connector for an external antenna instead. Everything else — pinout, flashing, firmware — is identical.

ESP32-WROOM-32U Recommended
Use this if the Rain Bird controller is somewhere with weak WiFi signal — a garage, utility closet, metal enclosure, or anywhere with a wall between the controller and your router. The external antenna (Section 2) can be positioned for a much better signal than a fixed on-board trace antenna.
ESP32-WROOM-32D
Fine if the controller is already in a spot with strong WiFi signal (open interior wall, close to the router). Saves the cost of the antenna and pigtail. If you're unsure, check your phone's WiFi bars at the controller's location before deciding.
If in doubt, buy the 32U. The antenna and pigtail are inexpensive relative to the cost of finding out later that signal is too weak and needing to redo the wiring.
4

Optional: Google Sheets logging setup

Completely optional. Without it, the device runs exactly the same — logger.py detects an unconfigured GOOGLE_SHEETS_URL and skips logging silently. Set this up if you want a remote, persistent history of every check cycle (rain readings, decisions, WiFi signal strength, free memory) without needing serial access.

1. Create the Sheet and Apps Script

  1. Create a new Google Sheet.
  2. Open Extensions → Apps Script.
  3. Write a doPost(e) function that parses the incoming JSON body and appends a row to the active sheet, prepending a timestamp. Auto-create a new tab (e.g. named by year-month) on first use each period if you want the sheet to stay organized long-term.
  4. Have it return a small JSON success response, e.g. {"status": "ok"}.

2. Deploy as a web app

  1. Deploy → New deployment → Web app.
  2. Execute as: Me.
  3. Who has access: Anyone — the ESP32 can't complete an OAuth flow, so the endpoint has to accept unauthenticated POSTs. There's no sensitive data in the payload (see below) and no way to read data back through this endpoint, only append to it.
  4. Copy the deployment URL — it looks like https://script.google.com/macros/s/<DEPLOYMENT_ID>/exec.

3. Configure the device

Put the deployment URL in secrets.py (copied from secrets_template.py — see 02-flash-guide.html):

GOOGLE_SHEETS_URL = "https://script.google.com/macros/s/<DEPLOYMENT_ID>/exec"

The firmware already includes google_ca.pem, the CA certificate needed for TLS verification against Google's servers — no extra download required.

What gets sent: event type, rain readings, forecast, decision, block reason, WiFi signal strength, free memory, and a device timestamp. No credentials, no WiFi SSID, no coordinates — see the Security Considerations section of the main README for the full data inventory.

4. Test it

Send a test POST from your PC to confirm the endpoint works before relying on it from the device:

curl -X POST -H "Content-Type: application/json" -d "{\"event\":\"test\"}" "https://script.google.com/macros/s/<DEPLOYMENT_ID>/exec"

A new row should appear in the Sheet. Once confirmed, flash the device with the real URL in secrets.py and check for rows after each 15-minute cycle.

Skipping this section entirely is a completely supported configuration — leave GOOGLE_SHEETS_URL as the template placeholder and move on to 02-flash-guide.html.
